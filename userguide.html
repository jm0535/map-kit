📂 Getting Started

Drag & drop any supported file onto the map, or click the Data Sources panel and use click to browse.

📍 Spatial Analysis - Geometric & Descriptive

Select a layer and run any tool. Results appear in the bottom panel and are added as exportable layers.

⊕ Mean Center & Standard Distance
Calculates the geographic mean of all point coordinates (the "centre of gravity") and a standard-distance circle. A small circle = tightly clustered data; a large circle = widely spread data. Use it to compare the geographic centroid of two groups or track shifts over time.
□ Bounding Box
Minimum axis-aligned rectangle enclosing all features. Shows width, height, and area (km²). Useful as a quick study-area extent or for comparing dataset sizes.
📏 Nearest Neighbor Index (NNI) (Clark & Evans 1954)
Compares observed mean nearest-neighbor distance with the expected distance under complete spatial randomness.
NNIInterpretation
NNI < 1🔴 Clustered (sites are closer together than random)
NNI ≈ 1⚪ Random
NNI > 1🟢 Dispersed (regularly spaced)
The z-score and p-value test if the pattern differs significantly from random. p < 0.05 + NNI < 1 = statistically significant clustering.
⬡ Convex Hull
Smallest convex polygon enclosing all features. Output includes perimeter (km) and area (km²). Useful for comparing species ranges, estimating home ranges, or defining a study boundary.
⬡ Convex Hull tool output showing the hull polygon, results panel, and Analysis drawer.
🧮 Calculate Field
Select a layer. Create a new attribute from values already in the table. Two modes:
ModeDescription
⚖ Weighted conditionsEach row is a test on a numeric field plus a weight; the score is the sum of weights where tests pass (otherwise 0 unless you set an Otherwise value). 1-8 rows.
📝 ExpressionType a formula using field names and the functions listed below.
Operators: + - * / % && || ! ? : ( ) > >= < <= == != (single = also works as equals).
Fields: Plain names (elevation_m) or double-quoted ("tree_cover_pct") as in QGIS; single quotes make text literals.
FunctionDescription
abs min max round(x[,n]) floor ceilBasic math
sqrt log exp powPowers and logs
coalesce(a,b,…) isnull(x)Null handling
if(cond,a,b)Conditional
length(s) concat(a,b,…)String operations
lower upperCase conversion
to_int to_num to_textType conversion
Nulls: Arithmetic with null gives null; division by zero gives null. In weighted-conditions mode a null or non-numeric value simply fails the test (Otherwise applies).
💡 QGIS equivalence
CASE WHEN "elev" >= 500 AND "elev" <= 1800 THEN 1 ELSE 0 END becomes (elev >= 500 && elev <= 1800 ? 1 : 0)
#ExamplePurpose
1(elev >= 500 && elev <= 1800 ? 1 : 0) + (cover >= 70 ? 1 : 0) + (rain >= 2500 ? 1 : 0)Index / proxy score
2(cover >= 80 ? 1 : 0)Binary flag
3rain / (elev + 1)Ratio
4concat(site, ' (', to_text(round(cover,0)), '%)')Label
This is not a suitability model and not a distribution model. You choose the tests, weights, and meaning. Copy the expression into your methods and record the GeoSpaX version from the page footer and the access date.
📏 Line Lengths
Haversine great-circle length for each line feature. Appends a length_km attribute; total is shown in the results panel.
▦ Polygon Areas
Spherical excess area (Chamberlain & Duquette 2009) for each polygon. Appends area_km2; accurate to < 0.3% at continental scale. Total shown in results.
• Centroids
Area-weighted centroid for polygons, coordinate mean for lines and points. Useful as a representative coordinate for labelling or joining.
○ Buffer Zones
Creates a circular buffer of a user-specified radius (km) around each feature as a 24-sided polygon. For production-grade buffers on lines or polygons, use QGIS → Vector → Geoprocessing → Buffer.
⛶ Simplify Geometries (Douglas-Peucker)
Reduces vertex count while preserving shape. Increase tolerance to simplify more aggressively. Useful when exporting to web maps where file size matters, or when polygon detail exceeds the target scale.
🌀 DBSCAN Clustering (Ester et al. 1996)
Groups points into density clusters without requiring a pre-set number of clusters. Points that don't fit any cluster are labelled noise (cluster = -1). Epsilon (neighbourhood radius) is auto-derived from 1.5× the median nearest-neighbor distance; MinPts = 3.
Each point gets a cluster attribute. Use DBSCAN first to explore groupings, then run Gi* or LISA for significance-tested hot spots.
📶 IDW Interpolation (Shepard 1968, p = 2)
Inverse Distance Weighting surface on a 50 × 50 grid. Estimates values at unsampled locations by weighting nearby observations more heavily. Good for a quick continuous surface (e.g. species richness, rainfall). Note: IDW can produce "bull's-eye" artefacts around isolated extreme values - consider this exploratory.
🟡 Point Density
Counts points within a moving kernel window on a 50 × 50 grid - a simple heat map of concentration. Not a significance test. Use Gi* for statistically tested hot spots.
🟠 Weighted Density
Same as Point Density but each point is weighted by a numeric attribute (e.g. richness, abundance). Shows where high-value features concentrate in space.
⬣ Voronoi / Thiessen Polygons
Divides the map so every location is assigned to its nearest point. Computed on a 120 × 120 raster grid (boundaries may appear slightly pixelated). Useful for allocating service areas or delineating nearest-feature catchments.
📊 Inferential Spatial Statistics

These four tools test whether spatial patterns are statistically significant and identify which specific features are driving them. All tools share common Weights and UTM projection settings.

Spatial Weights Options

OptionDescription
📏 Distance bandTwo features are neighbours if they are within d km. Default: the minimum distance that gives every feature at least one neighbour. Best for regular grids or continuous fields.
🗺 K-nearest neighbours (KNN)Each feature's k nearest features are its neighbours (default k = 8). Every feature always gets exactly k neighbours regardless of density. Best for irregular sampling or variable-density data.
🛰 UTM auto-projectionDistances are computed on an auto-selected UTM zone (not raw degrees), removing distortion near the equator and at high latitudes.
⚖ FDR correctionBenjamini-Hochberg False Discovery Rate adjustment prevents spurious hot spots when many features are tested at once. Leave it checked for confirmatory analysis; uncheck only for exploratory work.
🔥 Getis-Ord Gi* Hot Spot Analysis (Ord & Getis 1995)
For each feature, asks: "Is this feature's value, together with its neighbours', unusually high or low compared with the global mean?" Each feature receives a z-score and p-value.
ColourClassz-scoreMeaning
Deep red99% hot spotz ≥ 2.58Extremely strong evidence of a high-value cluster
Red95% hot spotz ≥ 1.96Strong evidence
Orange90% hot spotz ≥ 1.65Moderate evidence
GreyNot significant—No evidence of unusual clustering
Light blue90% cold spotz ≤ −1.65Moderate evidence of a low-value cluster
Blue95% cold spotz ≤ −1.96Strong evidence
Dark blue99% cold spotz ≤ −2.58Extremely strong evidence of a low-value cluster
💡 How to use results
A 95%+ hot spot cluster indicates a zone where high values are not random - likely a refugium, optimal habitat, or resource concentration worth prioritising for conservation. A cold spot cluster may indicate habitat degradation or harsh microclimate. Features marked "not significant" may simply lack enough neighbours - try increasing the band distance or switching to KNN.
🔥 Gi* results panel showing hot/cold spot counts, distance band, UTM zone, and FDR note.
🗺 Local Moran's I - LISA Cluster & Outlier Analysis (Anselin 1995)
LISA classifies each feature into a cluster or outlier type based on its own value relative to its neighbours. Significance is assessed by conditional permutation (999 randomisations).
ColourClassMeaning
HH - High-HighClusterHigh value surrounded by high neighbours. Core of a spatial hot spot. Prioritise for protection.
LL - Low-LowClusterLow value surrounded by low neighbours. Core of a spatial cold spot. Investigate cause (degradation, edge effect, microclimate).
HL - High-LowOutlierHigh value surrounded by low neighbours. Often a micro-refugium or remnant patch; high conservation value per unit area.
LH - Low-HighOutlierLow value surrounded by high neighbours. Unexpectedly depauperate patch within a rich landscape; potential degradation signal.
GreyNot significantPseudo-p > 0.05 (or FDR threshold).
High / Low are relative to the global mean. The pseudo-p-value comes from conditional permutation - how often a random re-labelling of neighbours produces a more extreme local Moran's I than the observed value.
🗺 LISA cluster map showing HH, LL, HL, and LH classifications with significance from 999 permutations.
📈 Global Moran's I - Spatial Autocorrelation Test (Cliff & Ord 1981)
Summarises the degree of spatial autocorrelation across the entire layer in a single index and tests whether it differs from zero.
ResultDescription
Moran's IObserved index (roughly −1 to +1, but not strictly bounded)
Expected I−1/(n−1); the mean under spatial randomness
VarianceCliff & Ord randomisation variance
z-score(I − E[I]) / √Var(I)
p-valueTwo-tailed probability under H₀: no spatial autocorrelation
ResultInterpretation
I >> E[I], z > 1.96, p < 0.05🔴 Positive autocorrelation - similar values cluster together. This confirms that Gi* and LISA results are meaningful.
I ≈ E[I]⚪ Random - no global spatial structure detected.
I << E[I], z < −1.96, p < 0.05🟢 Negative autocorrelation - dissimilar values are neighbours (checkerboard pattern).
A non-significant I does not rule out local hot spots - local clusters can exist even when the global average is near zero.
• Moran Scatterplot
A diagnostic chart that visualises Global Moran's I and shows which features drive autocorrelation. X-axis = standardised value (z-score) for each feature. Y-axis = spatial lag (mean standardised value of its neighbours). The slope of the regression line = Global Moran's I.
QuadrantMeaning
🔴 Upper-right (HH)High value, high-value neighbours. Positive autocorrelation (hot-spot core).
🔵 Lower-left (LL)Low value, low-value neighbours. Positive autocorrelation (cold-spot core).
🟡 Upper-left (LH)Low value, high-value neighbours. Spatial outlier.
🟢 Lower-right (HL)High value, low-value neighbours. Spatial outlier.
Points far from the origin in HH/LL correspond to LISA HH/LL clusters. Hover a point to see its site name and value.
