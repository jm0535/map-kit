v1.3.1 11 September 2026 Latest
UI Fixes, Keyboard Shortcuts, Documentation
New New Features
NewVisible rename button on each layer panel row. Previously only accessible via double-click or right-click context menu. Layer row buttons are now: ☰ drag, 👁 visibility, 🔍 zoom, ✏ rename, 📄 view fields, 🏷 labels, × remove.
NewKeyboard shortcuts: F toggle fullscreen, L toggle left panel, +/- zoom, A toggle Analysis drawer, Ctrl+Z undo, Ctrl+Y/Ctrl+Shift+Z redo, Ctrl+D duplicate selected features. All shortcuts suppressed when typing in text inputs.
NewRich export filename suggestions: auto-generated names include species, geometry type, UTM zone, and datum (e.g. Surname_lab_species_points_utm55S_WGS84).
NewCustom export filename input added to the export panel.
NewStandalone User Guide page (userguide.html) with enterprise-style layout, sidebar navigation, search filtering, scroll-spy, light/dark theme support, and actual GeoSpaX interface icons throughout.
Enh Enhancements
EnhDigitizing toolbar relocated from vertical right-side stack to horizontal bar at top-center of map. Button size reduced from 34px to 26px. No longer blocks the bottom panel.
EnhGlobal UTM auto-detect now works for any world location in both hemispheres, not just Papua New Guinea.
EnhCitation panel content now scrolls properly when the panel is smaller than the content.
EnhComprehensive User Guide expanded to cover all 33 feature sections including Open Data connectors, Map Composer, Raster Analysis, MCE, Conservation Planning, Landscape Metrics, SDM, Raster Reclassify, Provenance, How to Cite, References, and Licenses.
Fix Bug Fixes
FixElevation Profile Y-from-0 checkbox is now unchecked by default. Previously it was checked by default, forcing the Y-axis to start at 0 even when all elevations were positive.
FixEm-dash and en-dash removal: replaced all em-dashes and en-dashes with regular hyphens across all application and documentation files per user preference.
FixProject extension correction: fixed guide references from .geospax and .gsx to the correct .gspx extension.
Documentation
38 screenshots from screenshots/ folder embedded in the step-by-step guide DOCX. Guide now uses exact icons from GeoSpaX. README updated with panel layout, digitizing location, keyboard shortcuts, layer buttons, Composer access, conservation tools, Calculate Field, and UTM auto-detect.
v1.3.0 10 September 2026 Stable
GeoTIFF Symbology, Open Data Connectors, Composer Fixes
New New Features
NewGeoTIFF direct symbology (QGIS/ArcGIS workflow): GeoTIFF layers auto-selected in Symbology panel on load. Band selection, 8 colour ramps, min/max stretch with reset, opacity slider, continuous and classified rendering (Equal Interval, Quantile, Natural Breaks/Jenks, Manual breaks; 2-10 classes).
NewOpen Data Connectors (js/geospax-opendata.js): OSM Overpass, GBIF (with common-name search and pagination beyond 300 records), Natural Earth (bundled vector), WWF Terrestrial Ecoregions (846 polygons), Marine Ecoregions MEOW (232 polygons), World Bank indicators, USGS basemaps (Topo, Imagery, Shaded Relief).
NewView Fields feature for quick field inspection with pattern-based recognition and accurate source metadata for all open-source data connectors.
NewGlobal Save/Load Project promoted to the topbar so users can save/load from anywhere, not just the Analysis panel.
NewFine-grained zoom: 0.25 zoom increments in the main map and both composer modes (attached + detached).
NewSample GeoTIFF: PNG_BIO1_30s.tif (WorldClim BIO1 for Papua New Guinea) added to samples.
Enh Enhancements
EnhGradient legend auto-added when GeoTIFF loads: raster legend mode set to raster with gradient bar and min/mid/max labels.
EnhComposer raster rendering: GeoRasterLayer re-instantiated on the composer map with current symbology. The raster surface now appears in the composer, not just the legend.
EnhDetached composer sync: georaster data serialised via BroadcastChannel so the detached composer window also renders GeoTIFF surfaces.
EnhGBIF common-name search: search by common/vernacular name in addition to scientific name. User-controlled record limit (1-10000) with pagination.
EnhAnalysis panel: auto-collapse all sections by default, generic field-selector dropdown for filtering, attribute table pagination, custom scrollable filter dropdown, province filter for mainland/island subsetting.
Fix Bug Fixes
FixScalebar disappearing at low zoom levels: _metersPerPixel now uses lmap.project() (unrounded) instead of latLngToContainerPoint() (integer-rounded).
FixGeoTIFF parsing: fixed pixel data extraction for real WorldClim GeoTIFFs, symbology panel and attribute table not appearing, band-aware rendering (was hardcoded to band 0).
FixRaster analysis UI: fixed Histogram, Otsu, and Polygonize functions.
FixSmooth scrolling in all dropdowns and scrollable panels.
FixComposer popout sync: fixed export settings, view mirror, and ready-message spam bugs. Autosave recovery dialog suppressed in detached composer popout.
FixRemoved duplicate Save/Load from Analysis and Provenance panels (now only in topbar).
FixElevation profile Y-from-0 toggle not responding in some browsers.
Testing
677 tests passing across 19 Playwright test files (test_02-test_20). Full raster symbology, attribute table, composer, and open-data connector coverage.
v1.2.0 9 September 2026
Calculate Field Tool, Project Save/Load, CITATION.cff
New New Features
NewCalculate Field (js/gsx-calcfield.js): write a new attribute on any vector layer from existing fields, entirely client-side. Two modes: Weighted conditions (1-8 rows: numeric field + test + weight, optional Otherwise value) and Expression (small documented language with field insert, QGIS-style quoted field names). Expression language supports arithmetic, logic, comparisons, and functions (abs, min, max, round, floor, ceil, sqrt, log, exp, pow, coalesce, isnull, if, length, concat, lower, upper, to_int, to_num, to_text). Live preview of first 5 features. Optional graduated/categorized styling on the new field. QGIS CASE WHEN equivalence documented.
NewProject Save/Load: serialise entire map session (layers, styles, digitized features, bookmarks) to a .gspx JSON project file. Autosave with periodic localStorage recovery prompt on reload.
NewCITATION.cff: machine-readable citation metadata file added for Zenodo/DataCite integration.
NewHow to Cite tab in bottom panel with FORCE11-compliant citation formats: APA (7th ed.), Chicago (17th ed.), Harvard, BibTeX. Copy-to-clipboard for each format.
NewBLUEPRINT.md with full changelog and roadmap.
Enh Enhancements
EnhMap Composer enhancements: attribution label redesign (semi-transparent card, bold "Source:" prefix, draggable, toggleable), legend title and subtitle editing with live preview, legend resizing fix, enterprise resize handles (triangular grips), snap-to-grid (2-100px), sidebar collapse button, composer refresh button.
EnhExport panel restructure: collapsible sub-groups (Map Image, Elevation Profile, Bulk Data Export, Per-Layer Export) with single format-picker + Export button (ArcGIS Online-style UX).
EnhDrawing tools: snap-to-vertex, body drag, duplicate detection, Ctrl+D shortcut, theme colors, accessibility improvements, 8 bug fixes.
EnhMeasurement tool: replaced leaflet-measure with custom themed distance+area tool (geodesic distance, spherical area, non-overlapping UI, undo/finish/mode toggle).
EnhSymbology: QGIS-style tabbed renderer (Simple / Categorized / Graduated for vectors; Continuous / Classified for rasters). Vector graduated honours the Classes control (equal-interval classes).
EnhResponsive layout: large desktop (>=1600px, >=2000px) and tablet landscape (>=1024px) optimization.
Fix Bug Fixes
FixShapefile export: patched bundled shpwrite to use JSZip 3.x generateAsync() instead of removed generate(). Replaced broken location.href data-URI navigation with Blob download. Fixed naming to use layer name not geometry-type label.
FixMeasure tool: dblclick debounce, area min-points, theme-aware color, keyboard handler (Ctrl+Z only), panel hidden by default.
FixSelect mode: clear selection on cancel/Esc, replace (not append) on new drag.
FixSpatial statistics: Moran's I weights, DBSCAN eps/MinPts, Voronoi distance, area-weighted centroids, Polygon Areas subtract holes and sum all MultiPolygon parts, Clark-Evans z-test/p-value added to NNI, Moran scatterplot slope row-standardised.
FixHotspot/WLC/SDM tools: read features from geojsonFeatures for imported layers (was reading from stale source).
FixBasemaps: replaced broken Stadia tiles with Esri World Topo and CartoDB Dark Matter. Fixed broken Relief basemap.
FixBottom panel: fixed overflow hiding tabs, Chart.js canvas contained so panel never blows out the viewport.
FixRight panel conflict: drawer now pushes map instead of overlaying. Auto-collapse right panel when analysis drawer opens.

Upgrade Guide
How to upgrade between versions
💡 Zero-install upgrades
GeoSpaX is a browser application. Upgrading to the latest version simply requires refreshing the page at https://geospax.in4metrix.dev/. There is no installation step. Clear your browser cache if you do not see the new version (check the version number in the status bar).
v1.2.0 to v1.3.0
Save/Load moved: the Save Project and Load Project buttons moved from the Analysis and Provenance panels to the topbar. Old locations no longer have these buttons.
GeoTIFF workflow changed: GeoTIFF layers are now auto-selected in the Symbology panel on load. You no longer need to visit the Analysis panel first to style a raster.
GBIF limit: the GBIF record limit dropdown was replaced with a number input (1-10000). Common-name search is now supported.
v1.1.0 to v1.2.0
Old SDM functions removed: runBioclimSDM, runMahalanobisSDM, and runSDM were replaced by GSX.runBioclimSDM and GSX.runMahalanobisSDM. If you have custom scripts calling the old functions, update them to use the GSX. namespace.
Project files: .gspx project files saved in v1.2.0+ are compatible with v1.3.x. No migration needed.
v1.0.0 to v1.1.0
Rebrand: Map-Kit was renamed to GeoSpaX. Old bookmarks pointing to the GitHub Pages URL still work. The canonical URL is now https://geospax.in4metrix.dev/.
Analysis drawer: Spatial Analysis moved from inline panels to a dedicated slide-in drawer. Press A or click the 🧪 Analysis button in the top toolbar.

MINORNew features, backward-compatibleNo
