User Guide▼
▶ Getting Started
Drag & drop any supported file onto the map, or click the Import panel and use Choose file.
Supported formats: GeoJSON, KML/KMZ, GPX, Shapefile (.zip), CSV, XLSX, GeoTIFF.
CSV and XLSX files open a column mapper — pick the latitude, longitude, optional label, and elevation columns, and set the source CRS if your coordinates are projected (e.g. UTM).
Try the built-in sample: drag samples/sample_species_richness.geojson onto the map to explore all analysis tools with ready-made data.

▶ Map Navigation
Scroll to zoom — drag to pan — double-click to zoom in.
+ / − buttons top-left, or keyboard + / −.
F toggles fullscreen — L toggles the layer panel.
The minimap (bottom-right) shows your current viewport in context.
The status bar shows current zoom level, cursor coordinates, and visible feature count.

▶ Basemaps
Choose from 6 free basemaps: Topo (OpenTopoMap), Satellite (Esri Imagery), Streets (OSM), Relief (Esri Shaded Relief), Terrain (Esri World Topo), Dark (CartoDB Dark Matter).
Adjust basemap opacity with the slider beneath the selector.

▶ Layer Panel
• Eye icon — show / hide the layer
• Double-click name — rename inline (Enter to confirm, Esc to cancel)
• 🔍 button — zoom to layer extent
• × button — remove layer
• Opacity slider — per-layer transparency
• Label button — choose an attribute to show as map labels and set font size
• Click the layer name to select it for symbology editing

▶ Symbology
Simple Symbol — fill colour, marker size, opacity, stroke colour / width / style (solid, dashed, dotted, dash-dot). Shapes: circle, square, triangle, diamond, star, cross.
Categorized — one colour per unique value of a chosen attribute. Click legend entries on the map to rename them.
Graduated — numeric attribute divided into 2–10 classes along a colour ramp (Viridis, Heat, Cool, Terrain).
Reset returns the layer to its default style.

▶ Digitizing
Use the pencil toolbar (top-right of map) to draw Points, Lines, or Polygons.
Click the map to add vertices; double-click to finish a line or polygon. A crosshair cursor is shown during digitizing. Press Esc to cancel at any time.
After drawing, fill in the attribute form (name, description, category). Features are saved to the Drawn Features layer, which is fully exportable.

▶ Feature Info
Click any feature on the map to open its attribute card in the right panel. Shows geometry type, lat/lon, and all attributes.
Prev / Next buttons navigate through features in the same layer. Zoom to feature pans and zooms the map. Copy attributes copies the full table to clipboard.

▶ Attribute Table
Select a layer from the dropdown. All features appear in a searchable table. Click any row to zoom to that feature and open it in Feature Info. Use the search box to filter across all columns.

▶ Elevation Profile
Layers with an elevation column (elevation, elev, alt, or z) auto-populate the bottom profile panel. X-axis = distance (km), Y-axis = elevation (m a.s.l.).
Toggle layers on/off with checkboxes. Click a point on the chart to pan the map to that location. Drag the top edge of the panel to resize it.

▶ Export
Output CRS — choose a target coordinate reference system before exporting. Default is WGS 84 (EPSG:4326). Coordinates are reprojected client-side.

Data exports
• GeoJSON — RFC 7946 + named CRS member (read by QGIS & ArcGIS)
• CSV — flat table with longitude / latitude columns
• XLSX — Excel workbook (one layer per sheet when exporting all)
• Shapefile — zipped .shp / .dbf / .prj / .shx
• KML — OGC KML 2.2 (Google Earth, ArcGIS Earth)
• GPX — GPX 1.1 (GPS devices, Garmin, OsmAnd)

Map image exports
• Export map as PNG — current viewport at 72–400 DPI with title, legend, north arrow, scale bar
• Export map as PDF — same content as a PDF page
• Map Layout Composer — full print-layout tool with adjustable inset, gridlines, scale bar styles, and north arrow

▶ Spatial Analysis — Geometric & Descriptive
Select a layer and run any tool. Results appear in the panel and are added as exportable layers.

Mean Center & Standard Distance
Calculates the geographic mean of all point coordinates (the "centre of gravity") and a standard-distance circle. A small circle = tightly clustered data; a large circle = widely spread data. Use it to compare the geographic centroid of two groups or track shifts over time.

Bounding Box
Minimum axis-aligned rectangle enclosing all features. Shows width, height, and area (km²). Useful as a quick study-area extent or for comparing dataset sizes.

Nearest Neighbor Index (NNI)
Compares observed mean nearest-neighbor distance with the expected distance under complete spatial randomness (Clark & Evans 1954).
• NNI < 1 — clustered (sites are closer together than random)
• NNI ≈ 1 — random
• NNI > 1 — dispersed (regularly spaced)
The z-score and p-value test if the pattern differs significantly from random. p < 0.05 + NNI < 1 = statistically significant clustering.

Convex Hull
Smallest convex polygon enclosing all features. Output includes perimeter (km) and area (km²). Useful for comparing species ranges, estimating home ranges, or defining a study boundary.

Line Lengths
Haversine great-circle length for each line feature. Appends a length_km attribute; total is shown in the results panel.

Polygon Areas
Spherical excess area (Chamberlain & Duquette 2009) for each polygon. Appends area_km2; accurate to < 0.3% at continental scale. Total shown in results.

Centroids
Area-weighted centroid for polygons, coordinate mean for lines and points. Useful as a representative coordinate for labelling or joining.

Buffer
Creates a circular buffer of a user-specified radius (km) around each feature as a 24-sided polygon. For production-grade buffers on lines or polygons, use QGIS → Vector → Geoprocessing → Buffer.

Simplify (Douglas-Peucker)
Reduces vertex count while preserving shape. Increase tolerance to simplify more aggressively. Useful when exporting to web maps where file size matters, or when polygon detail exceeds the target scale.

DBSCAN Clustering
Groups points into density clusters without requiring a pre-set number of clusters (Ester et al. 1996). Points that don't fit any cluster are labelled noise (cluster = −1). Epsilon (neighbourhood radius) is auto-derived from 1.5× the median nearest-neighbor distance; MinPts = 3.
Each point gets a cluster attribute. Use DBSCAN first to explore groupings, then run Gi* or LISA for significance-tested hot spots.

IDW Interpolation
Inverse Distance Weighting surface (Shepard 1968, p = 2) on a 50 × 50 grid. Estimates values at unsampled locations by weighting nearby observations more heavily. Good for a quick continuous surface (e.g. species richness, rainfall). Note: IDW can produce "bull's-eye" artefacts around isolated extreme values — consider this exploratory.

Point Density
Counts points within a moving kernel window on a 50 × 50 grid — a simple heat map of concentration. Not a significance test. Use Gi* for statistically tested hot spots.

Weighted Density
Same as Point Density but each point is weighted by a numeric attribute (e.g. richness, abundance). Shows where high-value features concentrate in space.

Voronoi / Thiessen Polygons
Divides the map so every location is assigned to its nearest point. Computed on a 120 × 120 raster grid (boundaries may appear slightly pixelated). Useful for allocating service areas or delineating nearest-feature catchments.

▶ Inferential Spatial Statistics
These four tools test whether spatial patterns are statistically significant and identify which specific features are driving them. All tools share common Weights and UTM projection settings (see below).

Spatial Weights options
• Distance band — two features are neighbours if they are within d km. Default: the minimum distance that gives every feature at least one neighbour. Best for regular grids or continuous fields.
• K-nearest neighbours (KNN) — each feature's k nearest features are its neighbours (default k = 8). Every feature always gets exactly k neighbours regardless of density. Best for irregular sampling or variable-density data.
• UTM auto-projection — distances are computed on an auto-selected UTM zone (not raw degrees), removing distortion near the equator and at high latitudes.
• FDR correction — Benjamini-Hochberg False Discovery Rate adjustment prevents spurious hot spots when many features are tested at once. Leave it checked for confirmatory analysis; uncheck only for exploratory work.

Getis-Ord Gi* Hot Spot Analysis (Ord & Getis 1995)
For each feature, asks: "Is this feature's value, together with its neighbours', unusually high or low compared with the global mean?" Each feature receives a z-score and p-value. Features are coloured by confidence level:
Deep red — 99% hot spot (z ≥ 2.58): extremely strong evidence of a high-value cluster
Red — 95% hot spot (z ≥ 1.96): strong evidence
Orange — 90% hot spot (z ≥ 1.65): moderate evidence
Grey — not significant: no evidence of unusual clustering
Light blue — 90% cold spot (z ≤ −1.65)
Blue — 95% cold spot (z ≤ −1.96)
Dark blue — 99% cold spot (z ≤ −2.58): extremely strong evidence of a low-value cluster

How to use results: A 95%+ hot spot cluster indicates a zone where high values are not random — likely a refugium, optimal habitat, or resource concentration worth prioritising for conservation. A cold spot cluster may indicate habitat degradation or harsh microclimate. Features marked "not significant" may simply lack enough neighbours — try increasing the band distance or switching to KNN.

Local Moran's I — LISA Cluster & Outlier Analysis (Anselin 1995)
LISA classifies each feature into a cluster or outlier type based on its own value relative to its neighbours. Significance is assessed by conditional permutation (999 randomisations).

HH — High-High: high value surrounded by high neighbours → core of a spatial hot spot. Prioritise for protection.
LL — Low-Low: low value surrounded by low neighbours → core of a spatial cold spot. Investigate cause (degradation, edge effect, microclimate).
HL — High-Low: high value surrounded by low neighbours → spatial outlier. Often a micro-refugium or remnant patch; high conservation value per unit area.
LH — Low-High: low value surrounded by high neighbours → spatial outlier. Unexpectedly depauperate patch within a rich landscape; potential degradation signal.
Grey — not significant: pseudo-p > 0.05 (or FDR threshold).

High / Low are relative to the global mean. The pseudo-p-value comes from conditional permutation — how often a random re-labelling of neighbours produces a more extreme local Moran's I than the observed value.

Global Moran's I — Spatial Autocorrelation Test (Cliff & Ord 1981)
Summarises the degree of spatial autocorrelation across the entire layer in a single index and tests whether it differs from zero.

Results table:
• Moran's I — observed index (roughly −1 to +1, but not strictly bounded)
• Expected I — −1/(n−1); the mean under spatial randomness
• Variance — Cliff & Ord randomisation variance
• z-score — (I − E[I]) / √Var(I)
• p-value — two-tailed probability under H₀: no spatial autocorrelation

Interpretation:
• I >> E[I], z > 1.96, p < 0.05 → positive autocorrelation — similar values cluster together (e.g. high-richness sites near other high-richness sites). This confirms that Gi* and LISA results are meaningful.
• I ≈ E[I] → random — no global spatial structure detected.
• I << E[I], z < −1.96, p < 0.05 → negative autocorrelation — dissimilar values are neighbours (checkerboard pattern).
A non-significant I does not rule out local hot spots — local clusters can exist even when the global average is near zero.

Moran Scatterplot
A diagnostic chart that visualises Global Moran's I and shows which features drive autocorrelation.
X-axis = standardised value (z-score) for each feature. Y-axis = spatial lag (mean standardised value of its neighbours). The slope of the regression line = Global Moran's I.

Quadrant meanings:
• Upper-right (HH) — high value, high-value neighbours → positive autocorrelation (hot-spot core)
• Lower-left (LL) — low value, low-value neighbours → positive autocorrelation (cold-spot core)
• Upper-left (LH) — low value, high-value neighbours → spatial outlier
• Lower-right (HL) — high value, low-value neighbours → spatial outlier
Points far from the origin in HH/LL correspond to LISA HH/LL clusters. Hover a point to see its site name and value.
