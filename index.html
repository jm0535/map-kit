User Guide▼
Getting Started
Drag & drop or use the upload button to import GeoJSON, KML, GPX, Shapefile (.zip), CSV, XLSX, or GeoTIFF files.

Navigation
Scroll to zoom, drag to pan. Use the zoom buttons (top-left) or double-click to zoom in. Toggle fullscreen with the button top-left.

Basemaps
Switch between Topo, Satellite, Streets, Relief, Terrain, and Dark basemaps. Adjust basemap opacity with the slider.

Layers
Toggle layer visibility with checkboxes. Remove layers with the × button. The 🏷 button opens label controls — choose which attribute to display as map labels.

Symbology
Simple Symbol — Change fill color, size, opacity, stroke color/width/style, and marker shape (circle, square, triangle, diamond, star, cross).
Categorized — Color features by unique values of a selected attribute column.
Graduated — Color features along a color ramp based on numeric values. Choose column, number of classes, and color ramp (Viridis, Heat, Cool, Terrain).
Click Reset to return to the default single-color symbol.

Elevation Profile
Layers with elevation data automatically generate a profile chart in the bottom panel. Toggle layers on/off with checkboxes. Click a point on the profile to pan the map to that location. Drag the top edge of the panel to resize.

Spatial Analysis
Select a layer, then choose a tool:
• Mean Center — Geographic center with standard distance circle
• Bounding Box — Minimum bounding rectangle with area
• NNI — Nearest Neighbor Index (clustered/random/dispersed)
• Moran's I — Spatial autocorrelation with inverse-distance weights
• IDW — Inverse Distance Weighting interpolation surface
• Point Density — Concentration heat map
• Weighted Density — Attribute-weighted density surface
• DBSCAN — Density-based clustering (auto eps, MinPts=3)
• Convex Hull — Minimum convex polygon with perimeter
• Line Lengths — Haversine line distance calculation
• Polygon Areas — Spherical excess area calculation
• Centroids — Area-weighted centroid for polygons, mean center for points
• Simplify — Douglas-Peucker simplification (adjustable tolerance)
• Buffer — Circular buffer zones around features
• Voronoi — Thiessen polygon tessellation

Attribute Table
Select a layer to view its attribute table. Click a row to zoom to that feature and inspect its properties. Use the search box to filter rows.

Export
Export the map as PNG or PDF with configurable DPI. Export layer data as CSV or GeoJSON. The "Shapefile" option exports GeoJSON (convert with ogr2ogr/QGIS).

Keyboard Shortcuts
• +/- — Zoom in/out
• F — Toggle fullscreen
• L — Toggle layer panel
